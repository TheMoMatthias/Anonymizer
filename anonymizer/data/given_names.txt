# GIVEN NAMES ONLY -- no surnames, deliberately. Used as positive evidence, a list's
# PRECISION matters far more than its coverage, and German surnames collide massively
# with ordinary vocabulary: Stark, Gering, Koch, Bauer, Berg, Winter, Fuchs, Wolf,
# Richter, Jung and Klein are all attested surnames AND ordinary words. A surname list
# would therefore corroborate the exact false positives this work exists to remove.
# Given names collide far less, and where they do (Frank, Peter as loanwords) the
# collision is with a capitalized token that is a plausible name anyway.
#
# Curated and hand-written, NOT scraped: the large public name datasets in the
# hundreds-of-MB range are derived from a scraped/leaked social-network corpus, which
# has no place in a bank compliance tool. This is ~600 entries and under 8 KB.
#
# Coverage is deliberately "the common cases", because this is ONE of four
# corroboration sources -- a name column header, column-level inference and a GLiNER
# hit cover the rest. A rare or transliterated given name missing here is not a leak;
# it just has to be corroborated some other way.
#
